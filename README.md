# 旅行网站

一个精美的静态旅行网站，使用纯 HTML/CSS/JS 构建。

## 功能特性

- 🎨 现代简约设计风格
- 📱 完全响应式，适配手机/平板/电脑
- ✨ 平滑滚动动画效果
- 🔍 目的地搜索功能
- 📧 邮件订阅功能
- 🖼️ 精美的图片展示
- 🎯 导航栏滚动变色效果

## 页面结构

- **Hero 区域** - 全屏背景 + 搜索框
- **热门目的地** - 6个精选目的地卡片
- **特色体验** - 4种旅行体验类型
- **精选行程** - 3个打包行程方案
- **旅行故事** - 用户真实评价
- **数据统计** - 平台数据展示
- **订阅区域** - 邮箱订阅
- **页脚** - 导航链接 + 联系方式

## 使用方法

直接在浏览器中打开 `index.html` 即可查看效果。

## 自定义

- 修改 `index.html` 中的文字内容
- 替换图片链接（当前使用 Unsplash 图片）
- 调整颜色：修改 CSS 中的 `#3498db`（主色调）和 `#e74c3c`（价格颜色）
